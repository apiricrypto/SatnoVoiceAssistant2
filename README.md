# دستیار صوتی ساتنو برای اندروید

نسخه آزمایشی شخصی برای اجرای فرمان صوتی فارسی روی گوشی اندرویدی.

## قابلیت‌های نسخه 0.1

- تشخیص فرمان صوتی فارسی با سرویس Speech اندروید
- پیدا کردن مخاطب از دفترچه تلفن با نام فارسی یا انگلیسی
- تماس مستقیم با مخاطب
- ارسال SMS مستقیم به مخاطب
- ذخیره آخرین SMSهای ورودی
- فوروارد آخرین SMS ذخیره‌شده با فرمان صوتی

## فرمان‌های نمونه

```text
با علی تماس بگیر
به پیمان پیام بده جلسه ساعت پنج است
برای مجتبی پیامک بفرست سلام، لطفا تماس بگیر
آخرین پیام از علی را برای پیمان بفرست
آخرین پیام را برای علی بفرست
```

اگر چند مخاطب شبیه پیدا شود، اپ از شما انتخاب می‌خواهد.

## مجوزهای مورد نیاز

- Microphone: برای فرمان صوتی
- Contacts: برای جستجوی مخاطب
- Phone: برای تماس مستقیم
- SMS: برای ارسال و دریافت پیامک

این نسخه برای نصب شخصی ساخته شده و انتشار عمومی در Google Play به دلیل مجوزهای SMS/Call نیاز به بررسی‌های سخت‌گیرانه‌تر دارد.

## ساخت APK با بیلدر خودکار

روی لینوکس یا مک:

```bash
chmod +x build-tools/build-apk-linux.sh
./build-tools/build-apk-linux.sh
```

روی ویندوز PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-tools\build-apk-windows.ps1
```

این بیلدر Android command-line tools، SDK Platform، Build Tools و Gradle را دانلود می‌کند و در پایان APK را اینجا می‌سازد:

```text
app/build/outputs/apk/debug/app-debug.apk
```

اگر پروژه را روی GitHub بگذارید، فایل `.github/workflows/build-apk.yml` هم از بخش Actions یک APK آماده دانلود می‌سازد.

## ساخت APK در Android Studio

1. پوشه پروژه را در Android Studio باز کنید.
2. صبر کنید Gradle Sync کامل شود.
3. از مسیر زیر APK بسازید:

```text
Build > Build Bundle(s) / APK(s) > Build APK(s)
```

4. فایل APK معمولاً اینجا ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## نکته تست روی گوشی

بعد از نصب، همه مجوزها را فعال کنید. برای تست دریافت SMS، باید بعد از نصب اپ حداقل یک پیامک جدید دریافت شود تا در حافظه اپ ذخیره شود.
